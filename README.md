# Secure MCP 
MCP servers upset me. Why are they remotely hosted? Why do they need APIs when they just execute code, which LLMs can do already? Why did we try and reinvent REST? Let's just go back to how it was before MCPs and just use APIs the way they were intended, through SDKs. That is the goal of this project, to replace MCP servers with AI agents who execute functions defined for them that accomplish the same goals as MCP servers, but like without all the glaring issues that come with handing over the reigns of an AI that can execute code on your laptop to a third party service.
